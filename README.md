**Настольные часы с погодой, пятидневным прогнозом и сенсорным управлением.** Устройство получает время и погодные данные через Wi-Fi, сохраняет прогноз на SD-карту и продолжает работать, когда связь временно пропадает.

## Что понадобится

- Питание через Type-C.
- Домашняя сеть Wi-Fi **2,4 ГГц**.
- API-ключ погодного сервиса **Visual Crossing**. Ключ другого погодного сервиса не подойдёт.
- В играх понадобится что-то твердое ( например обратная сторона карандаша ), так как сенсор резистивный, и может криво считывать кординаты нажатий

Время синхронизируется через интернет после включения. Пока идёт синхронизация, на месте названия города отображается её состояние.

Первое подключение

1. На главном экране проведите пальцем **справа налево**, чтобы открыть меню. Для надёжного распознавания ведите палец по экрану, а не делайте короткий щелчок.
2. Нажмите **«Настройки»**. Часы отключатся от домашней сети и включат собственную точку доступа.
3. На телефоне подключитесь к сети **`ESP32-Weather-Setup`**, пароль **`12345678`**. Телефон может написать, что у этой сети нет интернета: для страницы настройки интернет не нужен.
4. Откройте в браузере **адрес, показанный на экране часов**.
5. Заполните поля и нажмите **«Сохранить и перезагрузить»**. Настройки запишутся во внутреннюю память платы; после перезапуска часы попробуют подключиться к указанной сети.

| Поле на странице | На что влияет |
| --- | --- |
| Название сети | К какой домашней сети подключаются часы. |
| Пароль сети | Пароль этой сети. |
| Город | Место, для которого загружается погода и которое показывается на главном экране. |
| Часовой пояс | Местное время на часах; указывается целым числом часов относительно UTC, например `3` для Москвы. |
| API-ключ погоды | Доступ к погодным данным Visual Crossing. |

Позже город, сеть, пароль, часовой пояс и API-ключ меняются тем же способом: **свайп влево → «Настройки»**. Пока открыт экран режима настройки, **любое касание самого экрана часов перезагружает плату**. Вводите данные на телефоне; чтобы выйти из режима настройки без сохранения, коснитесь экрана часов.

## Главный экран: куда нажимать

На нём видны день недели, дата, время, город, текущая температура, влажность, скорость ветра и прогноз на пять дней. Ветер показан в м/с. Время и дата появляются после синхронизации; если включить часы без интернета, до неё вместо времени может быть `--:--`.

| Действие | Результат |
| --- | --- |
| Провести пальцем справа налево по главному экрану | Открыть меню. |
| Нажать большую погодную иконку справа вверху | Открыть почасовую погоду на сегодня. |
| Нажать одну из пяти маленьких погодных иконок внизу | Открыть почасовую погоду для выбранного дня. Нажимать нужно именно на иконку. |
| Нажать в любом месте почасового экрана | Вернуться к часам. |

Если для выбранного дня нет сохранённых почасовых данных, появится `No hourly data`. Коснитесь экрана, чтобы вернуться. Нажатия на время, температуру, влажность и ветер отдельные экраны не открывают.

## Меню

На главном экране выполните свайп **влево**. В меню нажимайте плитку нужного пункта; кнопка **«Назад»** возвращает к часам. Свайп вправо в меню для возврата не нужен.

| Пункт | Что открывает и на что влияет |
| --- | --- |
| **Настройки** | Локальную Wi‑Fi-страницу для сети, города, часового пояса, погодного ключа и загрузки GIF. |
| **Инфо** | QR-код со ссылкой на страницу проекта. Считайте его камерой телефона; **«Назад»** возвращает в меню. |
| **Игры** | Экран выбора игр. Игры сделаны на коленке и нейронкой (для тестов экрана в основном) |
| **GIF** | Список анимаций с SD-карты и их воспроизведение. |
| **Обновление** | Проверку и загрузку новой версии программы. |
| **Назад** | Главный экран с часами. |

### Игры: куда нажимать

В пункте **«Игры»** нажмите название игры. Кнопка **«Назад»** на экране выбора возвращает в основное меню. Внутри большинства игр кнопка выхода подписана **`BACK`** и возвращает к выбору игр.

| Игра | Управление |
| --- | --- |
| **Змейка** | Касайтесь слева, справа, сверху или снизу относительно центра экрана, чтобы повернуть змейку в нужную сторону. Развернуть её сразу в противоположную сторону нельзя. После проигрыша нажмите в игровом поле для новой партии или **`Back`** для выхода. Во время самой партии отдельной кнопки выхода нет. |
| **2048** | Проводите пальцем по игровому полю вверх, вниз, влево или вправо: все плитки сдвинутся в эту сторону, одинаковые объединятся. **`RESET`** начинает заново, **`BACK`** выходит. |
| **Реакция** | Нажмите на экран, чтобы начать раунд. Затем касайтесь появляющейся яркой цели. Касание до появления цели или мимо неё считается промахом. После 20 целей показан результат; касание запускает новый раунд. **`BACK`** выходит. |
| **Арканоид** | Нажимайте или удерживайте нижние области **`< LEFT`** и **`RIGHT >`**, чтобы двигать платформу. Отбивайте шар и разбивайте блоки. После окончания партии касание запускает её заново; **`BACK`** находится справа вверху. |
| **Simon** | Сначала наблюдайте последовательность подсветки четырёх цветных областей, затем повторите её касаниями в том же порядке. **`BACK`** справа вверху. После ошибки или победы касание запускает новую игру. |
| **Сапёр** | Коснитесь закрытой клетки большого поля, затем нажмите справа **«Копать»**, **«Флажок»** или **«Отмена»**. «Копать» открывает клетку, «Флажок» помечает предполагаемую мину, «Отмена» снимает выбор. **`BACK`** справа вверху. |
| **Пятнашки** | Нажимайте на плитку рядом с пустым местом, чтобы передвинуть её. Цель — собрать числа по порядку. **`NEW`** перемешивает поле заново, **`BACK`** выходит. |

Из-за особенностей сенсора делайте отдельные касания с коротким отпусканием между ними. Для 2048 проводите пальцем по самому полю, а не по боковой панели.

### GIF с SD-карты

Пункт **«GIF»** показывает до трёх файлов на странице. Нажмите название файла, чтобы запустить его по кругу. **Любое касание во время воспроизведения возвращает к списку**. Внизу списка: **«Раньше»** и **«Дальше»** перелистывают страницы, **«Назад»** возвращает в меню.

GIF можно загрузить через страницу настроек: выберите один или несколько файлов в поле **«Файлы GIF»** и нажмите **«Загрузить GIF»**. Страница покажет ход отправки. При сбое доступна кнопка **«Повторить незагруженные»**. Это отдельное действие: оно не меняет Wi‑Fi и не перезагружает часы. Для веб-загрузки действуют ограничения **до 1500 Кбайт на файл и до 320 × 240 пикселей**. Удалять GIF через эту страницу нельзя.

Проигрыватель обнаруживает до 64 файлов и масштабирует изображение на экран; вручную добавленный GIF может иметь размер до 480 × 480 пикселей, но крупные анимации могут работать медленнее. GIF из меню **не заменяют заставку при включении**.

### Обновление программы

Откройте **«Обновление»** и нажмите верхнюю кнопку **«Обновить прошивку»**. Часы проверят релиз, затем при наличии новой версии скачают файл и покажут состояние и процент. Для этого нужны домашний Wi‑Fi, интернет и синхронизированное время. При успешной установке плата перезагрузится сама.

Нижняя кнопка **«Назад»** возвращает в меню. Если загрузка уже началась, **«Назад» её не отменяет**: работа продолжается в фоне. Надпись `v...` на экране обновления показывает версию, записанную в установленной программе; файл релиза содержит версию доступного обновления.

## Работа без интернета

Без интернета часы всё равно открывают главный экран и меню. Если погода уже была сохранена, она загружается при включении. Когда связи нет около 15 секунд, вместо города появляется **«Нет подключения»**. При пропаже домашнего Wi‑Fi часы повторяют подключение примерно раз в минуту; доступ к интернету при рабочем Wi‑Fi проверяется примерно раз в час.

Текущая погода при нормальной связи обновляется примерно раз в час, прогноз — раз в три часа. Если сеть недоступна, на экране остаётся последняя сохранённая погода. Если SD-карты нет или данные ещё ни разу не загружались, показывать старую погоду нечего. Игры, меню и локальная страница настроек не требуют доступа к интернету; проверка релиза и получение новых погодных данных требуют его.
