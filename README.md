# Инструкция по использованию ESP32 Weather Clock

## Описание устройства

ESP32 Weather Clock — настольный погодный информер на базе микроконтроллера ESP32 и TFT-дисплея ILI9341 (240x320 пикселей) с сенсорным управлением. Устройство подключается к Wi-Fi, получает текущее время через NTP-сервер, загружает погодные данные из API Visual Crossing и отображает их на цветном экране.

**Основные возможности:**
- Часы и дата с автоматической синхронизацией по NTP
- Текущая погода: температура, влажность, скорость ветра, иконка
- Прогноз на 5 дней с почасовым раскладом
- Кэширование погодных данных на SD-карту для работы офлайн
- Веб-портал настройки Wi-Fi, города и API-ключа
- Встроенная игра «Змейка»
- Анимация GIF при загрузке

**Аппаратная часть:**
- Плата: ESP32-2432S028 (ESP32 + TFT 240x320 + сенсор XPT2046)
- Дисплей: ILI9341, управление по SPI
- Сенсор: XPT2046 (касание пальцем)
- Память: SD-карта (кэш погоды, GIF-анимация, QR-код)
- Питание: Micro-USB или GPIO

## Первоначальная настройка

При первом запуске (или отсутствии сохранённых данных Wi-Fi) автоматически создастся точка доступа **ESP32-Weather-Setup** (пароль: `12345678`). Подключитесь к ней с телефона, откройте браузер и перейдите по IP-адресу, показанному на экране дисплея. На веб-странице заполните четыре поля:

- **SSID** — имя вашей домашней сети
- **Пароль** — ключ от этой сети
- **Город** — населённый пункт для получения прогноза (кириллицей или латиницей)
- **API-ключ** — токен от сервиса Visual Crossing (получить бесплатно на visualcrossing.com)

Нажмите «Сохранить и перезагрузить». После перезагрузки устройство подключится к вашей сети и начнёт загружать погодные данные.

## Навигация по экранам

### Главный экран

Отображает текущее время, дату, город, текущую погоду (температура, влажность, ветер, иконка) и прогноз на 5 ближайших дней. Данные обновляются автоматически: текущая погода — каждый час, прогноз — каждые 3 часа.

### Почасовой прогноз

Тапните на **иконку текущей погоды** (справа вверху) — откроется экран с 8 почасовыми записями на сегодня (03:00, 06:00, 09:00... 24:00) с температурой, ветром и давлением. Тапните на **иконку дня прогноза** внизу — увидите почасовой расклад на соответствующий день. Любой тап на почасовом экране возвращает обратно.

### Меню

**Свайп влево** на главном экране открывает меню с тремя кнопками:

| Кнопка | Действие |
|--------|----------|
| **Настройки** | Запускает Wi-Fi портал для смены SSID, пароля, города или API-ключа |
| **Инфо** | Показывает QR-код со ссылкой на GitHub-репозиторий проекта |
| **Змейка** | Запускает классическую игру «Змейка» |

Выход из меню — **свайп вправо**.

### Экран информации

Отображает QR-код с адресом `https://github.com/embedded-forge-26/WeatherClock`. Отсканируйте его камерой телефона для перехода к документации. Любой тап возвращает в предыдущий экран.

### Игра «Змейка»

Управляйте змейкой касанием экрана — она повернёт в сторону точки касания. Собирайте красные яблоки, избегайте столкновений со стенами и собственным хвостом. При проигрыше отображается финальный счёт. Тап перезапускает игру, кнопка **«Назад»** — возврат к погоде (кнопка появляется только на экране Game Over).

---

## Работа без Wi-Fi

Если сеть недоступна, устройство покажет экран «WiFi setup mode» с инструкцией по настройке. При наличии SD-карты с ранее сохранёнными JSON-файлами погоды данные будут загружены из кэша и отображены на экране.

## Анимация загрузки

При включении на дисплее проигрывается GIF-анимация с SD-карты (`/tenor.gif`) в течение 5 секунд.
